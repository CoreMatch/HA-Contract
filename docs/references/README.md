# External API References

此目录存放本项目所遵循的外部 API 标准。

## 重要说明

1. **协议标准 (Protocol Standards)**: 此目录存放的是**原始协议定义**。它们定义了外部系统（如 Minecraft 客户端、authlib-injector）期望的行为。
2. **只读性**: 这些文档是外部协议的权威定义，**严禁修改**。
3. **遵循原则**: 本项目在实现相关兼容层时，必须严格遵守这些文档定义的行为和数据结构。
